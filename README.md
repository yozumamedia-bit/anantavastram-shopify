# Ananta Vastram — Shopify theme

Custom Online Store 2.0 theme for Ananta Vastram (handwoven Tamil menswear), built on a stripped Dawn v9.0.0.

- Brief: `CLAUDE.md` · Spec: `docs/superpowers/specs/2026-09-14-ananta-vastram-theme-design.md` · Plan: `docs/superpowers/plans/2026-09-14-ananta-vastram-theme.md`
- **Store setup (metaobjects, metafields, pages, blog, policies, menus): [`docs/setup.md`](docs/setup.md)** — the theme renders empty states until that data exists.

## How it is built

- Every page is a JSON template made of `sections/av-*.liquid`; repeatable units are `snippets/av-*.liquid`. Dawn's cart, account, search, 404 and password templates stay stock and pick up the palette through the colour settings.
- Styles live in two files: `assets/av-base.css` (tokens, type roles, header, drawer, footer, opening) and `assets/av-sections.css` (one block per section).
- Scripts: `assets/av-opening.js` (once-per-session opening), `assets/av-reveal.js` (scroll reveal), `assets/av-video.js` (muted loops, play with sound). Dawn's `product-form.js` handles add to cart.
- Fonts: Marcellus and Karla from Shopify's font library; Rubik Mono One self-hosted (`assets/rubik-mono-one-400.woff2`, OFL); the Montage Serif wordmark is inline SVG in `snippets/av-wordmark.liquid`, generated by `scripts/build-wordmark.py` from the OTF (the OTF is never committed).

## Develop

```bash
npm i -g @shopify/cli
shopify theme check                      # must report 0 errors before every commit (CI enforces it)
shopify theme dev --store anantavastram.myshopify.com
shopify theme push --theme <development theme id> --store anantavastram.myshopify.com
```

The storefront is password-protected, so `theme dev` asks for the storefront password interactively.

**Never publish from the CLI.** No `theme push --live`, no `theme publish`. Publishing the live theme is a human decision made in Shopify admin.

## Branches

`develop` is the working branch (connected to an unpublished theme). `main` is what goes live, merged from `develop` only after review.
